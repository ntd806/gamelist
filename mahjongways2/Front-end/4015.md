# CMD 4015 — Lấy lịch sử chơi game

`cmd=4015` dùng để lấy danh sách lịch sử chơi game của user hiện tại. Response trả về là `cmd=4016`.

## 1. Request format

```json
{
  "cmd": 4015,
  "sessionToken": "VALID_SESSION",
  "roomId": 1,
  "filterType": "TODAY",
  "fromAt": null,
  "toAt": null,
  "timezone": "Asia/Ho_Chi_Minh",
  "page": 0,
  "limit": 20,
  "sort": "DESC"
}
```

## 2. Ý nghĩa field request

```text
cmd: command lấy lịch sử, cố định là 4015

sessionToken: token đăng nhập của user

roomId: ID phòng game cần lấy lịch sử

filterType: kiểu lọc thời gian
- TODAY: lấy lịch sử hôm nay
- LAST_7_DAYS: lấy lịch sử 7 ngày gần nhất, bao gồm hôm nay
- CUSTOM: frontend tự truyền fromAt và toAt

fromAt: thời gian bắt đầu dạng epoch millis, chỉ bắt buộc khi filterType = CUSTOM

toAt: thời gian kết thúc dạng epoch millis, chỉ bắt buộc khi filterType = CUSTOM

timezone: timezone dùng để tính ngày, mặc định Asia/Ho_Chi_Minh

page: số trang, bắt đầu từ 0

limit: số item mỗi trang, mặc định 20

sort: DESC hoặc ASC, mặc định DESC
```

## 3. Filter rule

### TODAY

Frontend gửi:

```json
{
  "cmd": 4015,
  "sessionToken": "VALID_SESSION",
  "roomId": 1,
  "filterType": "TODAY",
  "timezone": "Asia/Ho_Chi_Minh",
  "page": 0,
  "limit": 20,
  "sort": "DESC"
}
```

Backend tự tính:

```text
fromAt = 00:00:00.000 hôm nay theo Asia/Ho_Chi_Minh
toAt = 23:59:59.999 hôm nay theo Asia/Ho_Chi_Minh
```

### LAST_7_DAYS

Frontend gửi:

```json
{
  "cmd": 4015,
  "sessionToken": "VALID_SESSION",
  "roomId": 1,
  "filterType": "LAST_7_DAYS",
  "timezone": "Asia/Ho_Chi_Minh",
  "page": 0,
  "limit": 20,
  "sort": "DESC"
}
```

Backend tự tính:

```text
fromAt = 00:00:00.000 của 6 ngày trước
toAt = 23:59:59.999 hôm nay
```

Tức là đủ 7 ngày bao gồm hôm nay.

### CUSTOM

Frontend gửi:

```json
{
  "cmd": 4015,
  "sessionToken": "VALID_SESSION",
  "roomId": 1,
  "filterType": "CUSTOM",
  "fromAt": 1780419600000,
  "toAt": 1780505999999,
  "timezone": "Asia/Ho_Chi_Minh",
  "page": 0,
  "limit": 20,
  "sort": "DESC"
}
```

Với `CUSTOM`, bắt buộc phải có `fromAt` và `toAt`.

## 5. Ý nghĩa field response

```text
cmd: response command, cố định là 4016

timezone: timezone backend dùng để format ngày giờ

filterType: filter đang được áp dụng

fromAt / toAt: khoảng thời gian backend thực tế query

todaySummary: tổng kết riêng của hôm nay

pagination: thông tin phân trang

items: danh sách lịch sử chơi game
```

## 6. Ý nghĩa todaySummary

```text
sessionCount: hôm nay user đã chơi bao nhiêu phiên/spin

totalBet: tổng tiền cược thực tế hôm nay

totalWin: tổng tiền thắng hôm nay

totalProfit: tổng lời ròng hôm nay = totalWin - totalBet

currency: đơn vị tiền
```

Lưu ý:

```text
todaySummary luôn tính theo hôm nay, không phụ thuộc filterType.

Nếu filterType = LAST_7_DAYS hoặc CUSTOM, items sẽ trả theo filter đó, nhưng todaySummary vẫn là thống kê hôm nay.
```

## 7. Ý nghĩa item history

```text
spinId: ID kỹ thuật đầy đủ của spin, backend dùng để trace/debug

displaySpinId: ID ngắn để frontend hiển thị, ví dụ MW2-000004

createdAt: thời gian tạo spin dạng epoch millis

timeText: giờ hiển thị theo timezone, format HH:mm:ss

dateText: ngày hiển thị theo timezone, format dd/MM/yyyy

betOptionId: option cược đã dùng

betSize: bet size

betLevel: bet level

baseBet: base bet

lineBet: betSize × betLevel

totalBet: lineBet × baseBet

chargedAmount: số tiền thực tế bị trừ

totalWin: tổng tiền thắng của spin

profitAmount: lời ròng = totalWin - chargedAmount

payoutStatus: trạng thái payout

mode: BASE hoặc FREE_SPIN

bigWin: true nếu winLevel khác NONE

winLevel: NONE | BIG_WIN | MEGA_WIN | BIG_MEGA_WIN

winMultiplier: totalWin / totalBet

freeSpinTriggered: spin này có kích hoạt Free Spin không

jackpotTriggered: hiện tại jackpot đang disable nên thường là false

dailySpinCount: số thứ tự lượt chơi trong ngày
```

## 8. Quy tắc tính tiền

Paid spin:

```text
chargedAmount = totalBet
profitAmount = totalWin - totalBet
```

Free Spin:

```text
chargedAmount = 0
profitAmount = totalWin
```

Lưu ý: Free Spin vẫn có `totalBet` để làm reference tính payout/winLevel, nhưng không cộng vào tổng tiền cược thực tế vì không trừ tiền user.

## 9. Win level

```text
NONE         = totalWin < 10x totalBet
BIG_WIN      = totalWin >= 10x totalBet
MEGA_WIN     = totalWin >= 25x totalBet
BIG_MEGA_WIN = totalWin >= 50x totalBet
```

Mỗi spin chỉ trả một `winLevel` cao nhất đạt được.

Ví dụ:

```text
totalBet = 450
totalWin = 4,500   => BIG_WIN
totalWin = 11,250  => MEGA_WIN
totalWin = 22,500  => BIG_MEGA_WIN
```

## 10. Các field không trả trong 4016

`4016` là history summary list, không trả full result.

Không trả trong `items[]`:

```text
result
animationReels
cascadeSteps
animationColumns
animationMeta
visualWins
freeSpin full object
jackpot full object
state full object
clientRequestId
```

Nếu frontend cần xem chi tiết một phiên chơi, dùng `cmd=4017`.

## 11. Command xem chi tiết lịch sử

Frontend lấy `displaySpinId` từ `4016`, sau đó gọi:

```json
{
  "cmd": 4017,
  "sessionToken": "VALID_SESSION",
  "displaySpinId": "MW2-000004",
  "timezone": "Asia/Ho_Chi_Minh"
}
```

Backend trả `cmd=4018`, trong đó mới có full result của spin.
