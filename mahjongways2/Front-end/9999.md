## 4. Super Mega Win

Trong backend nên map về enum thật:

```txt
BIG_MEGA_WIN
```

Payload:

```json
{
  "cmd": 9999,
  "scenario": "WIN_LEVEL_BASE",
  "targetWinLevel": "BIG_MEGA_WIN",
  "sessionToken": "tester-session-001",
  "clientRequestId": "big-mega-win-001",
  "gameCode": "MAHJONG_WAYS_2",
  "roomId": 1,
  "betOptionId": "R1_BS_250_BL_9",
  "jackpotEnabled": false
}
```

Cho alias:

```txt
SUPER_MEGA_WIN
SUPERMEGAWIN
BIGMEGAWIN
BIG_MEGA_WIN
```

nhưng response chuẩn vẫn nên là:

```txt
BIG_MEGA_WIN
```
