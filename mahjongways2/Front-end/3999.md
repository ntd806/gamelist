# 4. Format response 3999 chuẩn

Nên thống nhất response cho mọi socket/REST spin error:

```json
{
  "cmd": 3999,
  "errorCode": 1402,
  "message": "BET_PENDING",
  "balance": "200,000.00",
  "requiredAmount": null,
  "totalBet": null,
  "shortfall": null,
  "payoutStatus": "BET_PENDING",
  "clientRequestId": "xxx",
  "spinId": "SPIN_xxx",
  "roundId": "RND_xxx",
  "seamless": {
    "enabled": true
  }
}
```

Quy tắc:

```text
errorCode: unique int, không trùng cho lỗi khác.
message: unique uppercase string, không trùng cho lỗi khác.
payoutStatus: trạng thái xử lý tiền, được phép trùng.
balance/requiredAmount/shortfall: chỉ có ở lỗi balance.
clientRequestId/spinId/roundId: có nếu lỗi xảy ra trong spin flow.
seamless.enabled: true nếu lỗi liên quan wallet/seamless.
```
